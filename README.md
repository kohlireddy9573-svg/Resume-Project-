# Portfolio Website

This project is a personal portfolio website built using HTML and CSS. It showcases a professional profile, work experience, education, projects, and contact information.

## Project Structure

- `index.html` – main page structure and content
- `style.css` – styling, layout, and responsive design
- `image/` – project images and assets used in the portfolio

## Features

- Clean and modern portfolio design
- Responsive layout for desktop and mobile devices
- Sections for about, education, experience, projects, and contact
- Professional styling with an academic and tech-focused aesthetic

## How to Run

Open `index.html` in any browser to view the portfolio locally.

## Deployment

This project can be hosted on GitHub Pages or any static web hosting service.
